# Minion Rush Modding Tools

This repository contains all Python scripts I use for modding the kiddy game *Despicable Me: Minion Rush* Windows edition (you can find my mod [here](https://archive.org/details/minion-rush-windows-modded-v-1)). You can find them in `scripts` folder. They are all enchanced by AI.

## List of all scripts
* `minion_rush_config_codec.py`: used for editing contents of `filesConfig.dat` and `config##########`
* `bclara_editor.py`: used for editing contents of Gameloft's proprietary `.bclara` files
* `blibclara_library_editor.py`: used for editing contents of Gameloft's proprietary `.blibclara` files
* `jpk.py`: used for extracting and replacing contents of `.jpk` archive files
* `jelly_lab_area_json_editor.py`: wrapper over `blibclara_library_editor.py` to facilitate editing of `maplib.blibclara`
* `minion_rush_save_editor.py`: used for modifying contents of `savegame` (if you want to view and edit contents of `MapMgr`, you need to supply `jelly_lab_catalog.json` generated by `extract_jelly_lab_catalog.py`)
* `extract_jelly_lab_catalog.py`: used for extracting Jelly Lab information from `maplib.blibclara` in `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk`
* `maplib_to_sqlite.py`: used for converting `maplib.blibclara` into a SQLite database
* `texts_json_editor.py`: used for modifying key-value pairs in `text.bin` or `texts.texts` (if you are modifying Android `texts.texts`, you must supply the corresponding key file `texts.texts.keys`)
* `clone_last_area.py`: it takes `maplib.blibclara` for input and clones its last area and make it new last area
* `strip_costume_iap.py`: a simple script to remove all costume In-App-Purchase (IAP) prices in the library `Minion_Costumes_update1` from `designlib.blibclara`
* `android_to_windows_areas61_76_importer.py`: used for importing area 61 to area 76 data from Android 5.7.0 `maplib.blibclara` into Windows `maplib.blibclara`

## Workflow

### Modifying Power-ups and Costumes

To change internal settings of power-ups and costumes, first fetch a copy of `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk` from `LocalState\dlcs` and put it in the `scripts` folder then run:
```
python jpk.py extract dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk designlib.blibclara designlib.blibclara
```
The file `designlib.blibclara` contains 22 libraries:
```
Collisions
Materials
Minion_Costumes_update1
Minion_Costumes_Appearances
Minion_Costumes_data_update1
LC_Minion_Costumes
LC_Minion_Costumes_data
Buyables
Prices
MenuUI
Decorations
Globals
Globals_Multiplayer
Globals_Minigames
Globals_Cameras
Online
LevelDef
Effects2
Effects3
Effects_Multiplayer
Platforms
OpenGraphLib
```
The only relevant libraries for our interests are `Minion_Costumes_update1` which contains essential data for all costumes, and `LevelDef` which contains essential data for all power-ups.

To edit costume settings, run:
```
python blibclara_library_editor.py decode designlib.blibclara Minion_Costumes_update1 output.json
```
To edit power-up settings, run:
```
python blibclara_library_editor.py decode designlib.blibclara LevelDef output.json
```
Make any necessary changes to `output.json`. As an example, let's attempt increase duration of the Freeze Ray power-up. They are controlled by entities `FreezeRay_main_upgrade_00x` where x ranges from 0 to 5 inside the LevelDef library. Suppose you want Freeze Ray to last for 1min at maximum level. First, search the string `"FreezeRay_main_upgrade_005"` inside `output.json`. You will find something like this:
```
{
  "kind": "entity",
  "entity": {
    "class": "BonusUpgrade",
    "name": "FreezeRay_main_upgrade_005",
    "properties": [
      {
        "name": "price",
        "type_index": 228,
        "type_code": 8,
        "subtype": 0,
        "named_elements": false,
        "elements": [
          {
            "value": "/Prices/Prices_Bonuses/Prices_FreezeRay/Prices_FreezeRay_Level_5"
          }
        ]
      },
      {
        "name": "value",
        "type_index": 76,
        "type_code": 2,
        "subtype": 2,
        "named_elements": false,
        "elements": [
          {
            "value": 18
          }
        ]
      },
      {
        "name": "OpenGraphObj",
        "type_index": 143,
        "type_code": 8,
        "subtype": 0,
        "named_elements": false,
        "elements": [
          {
            "value": "/OpenGraphLib/UpgradeFreezeRay"
          }
        ]
      }
    ]
  }
}
```
Inside the properties field, all you have to do is to change the value from 18 to 60 like this:
```
{
  "name": "value",
  "type_index": 76,
  "type_code": 2,
  "subtype": 2,
  "named_elements": false,
  "elements": [
    {
      "value": 60
    }
  ]
}
```

To save all changes, patch the JPK using the following commands:
```
python blibclara_library_editor.py encode designlib.blibclara output.json designlib_modified.blibclara
python jpk.py replace dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk designlib.blibclara designlib_modified.blibclara dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk
```
The modified JPK will be saved to `dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk`.

### Editing Levels and Adding an Area to Jelly Lab

To add an additional area to Jelly Lab, fetch `maplib.blibclara` from `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk` using
```
python jpk.py extract dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk maplib.blibclara maplib.blibclara
```
Then use `clone_last_area.py` to create an area template for editing:
```
python clone_last_area.py maplib.blibclara maplib_extended.blibclara
```
Suppose the last area in `maplib.blibclara` is 77. Run the following to extract level data for area 78
```
python jelly_lab_area_json_editor.py decode maplib_extended.blibclara 78 area78.json
```
Make any necessary changes to `area78.json`. You may find `jelly_lab_all_possible_values_used_unused.txt` helpful. To save your changes, run
```
python jelly_lab_area_json_editor.py encode maplib_extended.blibclara 78 area78.json maplib_mod.blibclara
python jpk.py replace dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk maplib.blibclara maplib_mod.blibclara dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk
```
The modified JPK will be saved to `dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk`.
