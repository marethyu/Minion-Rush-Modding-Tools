# Minion Rush Modding Tools

This repository contains all Python scripts I use for modding the kiddy game *Despicable Me: Minion Rush* Windows edition (you can find my mod [here](https://archive.org/details/minion-rush-windows-modded-v-1)). You can find them in `scripts` folder. They are all enchanced by AI.

## List of all scripts
* `minion_rush_config_codec.py`: used for editing contents of `filesConfig.dat` and `config##########`
* `blibclara_editor.py`: used for editing contents of Gameloft's proprietary `.blibclara` files
* `jpk.py`: used for extracting and replacing contents of `.jpk` archive files
* `jelly_lab_area_json_editor.py`: wrapper over `blibclara_editor.py` to facilitate editing of `maplib.blibclara`
* `costume_json_editor.py`: wrapper over `blibclara_editor.py` to facilitate editing costume-related data in `designlib.blibclara`
* `minion_rush_save_editor.py`: used for modifying contents of `savegame` (if you want to view and edit contents of `MapMgr`, you need to supply `jelly_lab_catalog.json` generated by `extract_jelly_lab_catalog.py`)
* `extract_jelly_lab_catalog.py`: used for extracting Jelly Lab information from `maplib.blibclara` in `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk`
* `maplib_to_sqlite.py`: used for converting `maplib.blibclara` into a SQLite database
* `text_bin_english_json_editor.py`: used for adding deleting key-value pairs in `text.bin`
* `clone_last_area.py`: it takes `maplib.blibclara` for input and clones its last area and make it new last area
* `strip_costume_iap.py`: a simple script to remove all costume In-App-Purchase (IAP) prices in `designlib`
* `android_to_windows_areas61_76_importer.py`: used for importing area 61 to area 76 data from Android 5.7.0 `maplib.blibclara` into Windows `maplib.blibclara`

## Workflow

### Modifying Power-ups and Costumes

If you want to change internal settings of power-ups and costumes, first fetch a copy of `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk` from `LocalState\dlcs` and put it in the `scripts` folder then run the following commands:
```
python jpk.py extract dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk designlib.blibclara designlib.blibclara
python blibclara_editor.py decode designlib.blibclara designlib.json
```
Make any necessary changes to `designlib.json` then patch the JPK using the following commands:
```
python blibclara_editor.py encode designlib.blibclara designlib.json designlib_modified.blibclara
python jpk.py replace dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk designlib.blibclara designlib_modified.blibclara dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk
```
The modified JPK will be saved to `dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk`.

### Editing Levels and Adding an Area to Jelly Lab

If you want to add an additional area to Jelly Lab, fetch `maplib.blibclara` from `dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk` using
```
python jpk.py extract dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk maplib.blibclara maplib.blibclara
```
Then use `clone_last_area.py` to create an area template for editing:
```
python clone_last_area.py maplib.blibclara maplib_extended.blibclara
```
Suppose the last area in `maplib.blibclara` is 77. Run the following to extract level data for area 78
```
python jelly_lab_area_json_editor.py decode maplib_extended.blibclara 78 area78.json
```
Make any necessary changes to `area78.json`. You may find `jelly_lab_all_possible_values_used_unused.txt` helpful. To save your changes, run
```
python jelly_lab_area_json_editor.py encode maplib_extended.blibclara 78 area78.json maplib_mod.blibclara
python jpk.py replace dlc_v7_data_mandatory_w8wp8_up23_data_95.jpk maplib.blibclara maplib_mod.blibclara dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk
```
The modified JPK will be saved to `dlc_v7_data_mandatory_w8wp8_up23_data_95_modified.jpk`.
